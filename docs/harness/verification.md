# Verification Routing

| 変更種別 | 最低限の検証 | 追加検証 |
|---|---|---|
| 文書のみ | リンク・整合性 | 人間レビュー |
| ロジック | lint / typecheck / unit test | 境界値・回帰 |
| API / DB | 自動テスト・権限確認 | staging相当の実動作 |
| UI | build・機能テスト | スクリーンショット・rubric |
| 高影響変更 | 基本検証 | 独立レビュー・人間承認 |

原則はルールベース検証を先に置き、ルールで表現できない品質だけをビジュアル・LLM・人間評価へ拡張することです。
